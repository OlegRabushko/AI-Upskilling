Модуль 7

Workflows, агенты и состояние

Отдельные ответы и вызовы инструментов пора собрать в управляемый конвейер: классификация → поиск → ответ → проверка уверенности → эскалация человеку. Вы научитесь хранить состояние, память и ветвления, а затем перенесёте всё в LangGraph.

Опирается на RAG (модуль 5) и tools (модуль 6). Для финального шага: pip install langgraph.

Задания модуля

  1. Workflow против agent
  2. Управление состоянием
  3. Ветвления и эскалация
  4. Память агента
  5. Реализация на LangGraph
Задание 7.1

Workflow против agent

Что делаем: реализуем один сценарий двумя способами — жёстким workflow и свободным агентом. Зачем: понять, когда нужна предсказуемая последовательность, а когда — автономия.

Шаг 1Workflow — фиксированные шаги 

def workflow(question: str) -> str:
    category = classify(question)      # шаг 1 (детерминирован)
    docs = retrieve(question)          # шаг 2
    return generate(question, docs)    # шаг 3

# порядок всегда один и тот же — легко тестировать и предсказывать

Шаг 2Заглушки шагов

def classify(q: str) -> str:
    return "account" if "парол" in q.lower() else "other"

def retrieve(q: str) -> list[str]:
    return ["account.md"] if "парол" in q.lower() else []

def generate(q: str, docs: list[str]) -> str:
    return "Сбросьте пароль по ссылке из письма." if docs else "Нет данных."

Шаг 3Agent — сам выбирает шаги 

# агент из модуля 6.2 сам решает, искать ли, звать ли инструмент
answer = agent("Не приходит письмо для сброса пароля, заведи тикет если нужно")
print(answer)

Шаг 4Сравниваем свойства

Workflow Agent
Предсказуемость высокая ниже
Гибкость низкая высокая
Отладка простая сложнее
Когда применять известный процесс открытая задача

Шаг 5Гибрид

# Практика: жёсткий каркас workflow, а внутри отдельных шагов — локальная автономия.
def hybrid(question: str) -> str:
    docs = retrieve(question)          # детерминированный поиск
    if not docs:
        return agent(question)         # сложный случай — отдаём агенту
    return generate(question, docs)
Вывод: большинство продакшн-систем — гибрид: предсказуемый каркас с точечной автономией.
Задание 7.2

Управление состоянием

Что делаем: вводим объект состояния, который проходит через все шаги. Зачем: шагам нужно передавать данные друг другу явно и прозрачно для отладки.

Шаг 1Описываем состояние

from dataclasses import dataclass, field

@dataclass
class State:
    question: str
    category: str | None = None
    docs: list = field(default_factory=list)
    answer: str | None = None
    confidence: float = 0.0
    needs_human: bool = False

Шаг 2Шаги меняют состояние

def step_classify(s: State) -> State:
    s.category = "account" if "парол" in s.question.lower() else "other"
    return s

def step_retrieve(s: State) -> State:
    s.docs = ["account.md"] if s.category == "account" else []
    return s

Шаг 3Генерация с оценкой уверенности 

def step_generate(s: State) -> State:
    if s.docs:
        s.answer = "Сбросьте пароль по ссылке из письма."
        s.confidence = 0.9
    else:
        s.answer = None
        s.confidence = 0.2
    return s

Шаг 4Прогоняем состояние через конвейер 

def run(question: str) -> State:
    s = State(question=question)
    for step in (step_classify, step_retrieve, step_generate):
        s = step(s)
        print("after", step.__name__, "->", s)   # видно эволюцию состояния
    return s

run("Не приходит письмо для сброса пароля")

Шаг 5Состояние как лог отладки 

final = run("Вопрос без ответа в базе")
print("confidence:", final.confidence, "answer:", final.answer)
Вывод: явное состояние = прозрачность. В любой момент видно, что уже известно и чего не хватает.
Задание 7.3

Ветвления и эскалация

Что делаем: добавляем решение «ответить или передать человеку». Зачем: не каждую задачу можно и нужно закрывать автоматически — важен безопасный выход.

Шаг 1Узел принятия решения

def step_decide(s: State) -> State:
    if s.confidence < 0.5:
        s.needs_human = True
        s.answer = "Передаю обращение оператору."
    return s

Шаг 2Конвейер с ветвлением

def run(question: str) -> State:
    s = State(question=question)
    for step in (step_classify, step_retrieve, step_generate, step_decide):
        s = step(s)
    return s

Шаг 3Проверяем обе ветки

ok = run("Не приходит письмо для сброса пароля")
esc = run("Хочу узнать про слияние компаний")
print("auto:", ok.needs_human, "|", ok.answer)
print("escalated:", esc.needs_human, "|", esc.answer)

Шаг 4Очередь к человеку

HUMAN_QUEUE: list[dict] = []

def maybe_escalate(s: State):
    if s.needs_human:
        HUMAN_QUEUE.append({"question": s.question, "category": s.category})

maybe_escalate(esc)
print("В очереди к оператору:", HUMAN_QUEUE)

Шаг 5Тесты ветвлений

def test_auto():
    assert run("Как сбросить пароль?").needs_human is False
def test_escalation():
    assert run("Непонятный редкий вопрос").needs_human is True
test_auto(); test_escalation()
print("Ветвления корректны.")
Вывод: порог уверенности + эскалация — безопасный «аварийный выход» агента к человеку.
Задание 7.4

Память агента

Что делаем: добавляем краткосрочную (диалог) и долгосрочную (профиль) память. Зачем: агент должен помнить контекст разговора и факты о пользователе между сессиями.

Шаг 1Краткосрочная память диалога 

class Conversation:
    def __init__(self):
        self.history: list[dict] = []
    def add(self, role: str, content: str):
        self.history.append({"role": role, "content": content})
    def as_messages(self) -> list[dict]:
        return self.history[-10:]     # держим только последние реплики

Шаг 2Долгосрочная память в SQLite 

import sqlite3
db = sqlite3.connect("memory.db")
db.execute("CREATE TABLE IF NOT EXISTS prefs (user TEXT, key TEXT, value TEXT)")

def remember(user: str, key: str, value: str):
    db.execute("INSERT INTO prefs VALUES (?,?,?)", (user, key, value))
    db.commit()

def recall(user: str) -> dict:
    rows = db.execute("SELECT key, value FROM prefs WHERE user=?", (user,))
    return {k: v for k, v in rows}

Шаг 3Сохраняем факт о пользователе 

remember("u1", "language", "ru")
remember("u1", "plan", "premium")
print(recall("u1"))

Шаг 4Используем память в ответе 

from llm_client import LLMClient
bot = LLMClient()

def answer_with_memory(user: str, question: str, conv: Conversation) -> str:
    prefs = recall(user)
    conv.add("user", question)
    system = f"Учитывай профиль пользователя: {prefs}. Отвечай на его языке."
    reply = bot.ask(question, system=system)
    conv.add("assistant", reply)
    return reply

conv = Conversation()
print(answer_with_memory("u1", "Какой у меня тариф?", conv))

Шаг 5Память против состояния

Понятие Живёт Пример
State в пределах одного запроса найденные docs, confidence
Краткосрочная память в пределах диалога последние реплики
Долгосрочная память между сессиями язык, тариф, история
Вывод: state, краткосрочная и долгосрочная память — три разных уровня; путать их — частая ошибка новичков.
Задание 7.5

Реализация на LangGraph

Что делаем: переносим конвейер в граф LangGraph с условным переходом к человеку. Зачем: фреймворк даёт явные узлы, рёбра, визуализацию и управление состоянием из коробки.

Шаг 1Состояние графа

from typing import TypedDict
from langgraph.graph import StateGraph, END

class GState(TypedDict):
    question: str
    docs: list
    answer: str
    confidence: float

Шаг 2Узлы графа

def n_retrieve(s: GState) -> GState:
    s["docs"] = ["account.md"] if "парол" in s["question"].lower() else []
    return s

def n_generate(s: GState) -> GState:
    if s["docs"]:
        s["answer"], s["confidence"] = "Сбросьте пароль по ссылке.", 0.9
    else:
        s["answer"], s["confidence"] = "", 0.2
    return s

def n_human(s: GState) -> GState:
    s["answer"] = "Передано оператору."
    return s

Шаг 3Условный переход

def route(s: GState) -> str:
    return "ok" if s["confidence"] >= 0.5 else "human"

Шаг 4Собираем граф

g = StateGraph(GState)
g.add_node("retrieve", n_retrieve)
g.add_node("generate", n_generate)
g.add_node("human", n_human)
g.set_entry_point("retrieve")
g.add_edge("retrieve", "generate")
g.add_conditional_edges("generate", route, {"ok": END, "human": "human"})
g.add_edge("human", END)
app = g.compile()

Шаг 5Запуск и визуализация

print(app.invoke({"question": "Как сбросить пароль?"}))
print(app.invoke({"question": "Редкий непонятный вопрос"}))
# print(app.get_graph().draw_mermaid())   # схема графа в формате Mermaid
