Модуль 5

RAG: ingestion, retrieval и evidence

Теперь KnowledgeBot будет отвечать не из «головы» модели, а по вашим документам — и указывать источники. Вы пройдёте весь путь: загрузка и нарезка документов, эмбеддинги, поиск, grounding ответа и продвинутые приёмы.

Установка: pip install chromadb openai python-dotenv. Положите 3–5 файлов .md в папку docs/ (например vacation.md, account.md, billing.md).

Задания модуля

  1. Ingestion и chunking
  2. Embeddings и vector DB
  3. Retrieval
  4. Grounding и источники
  5. Advanced RAG
Задание 5.1

Ingestion и chunking

Что делаем: читаем документы и режем их на фрагменты. Зачем: модель и поиск работают с небольшими кусками; целый документ и дорог, и «размывает» релевантность.

Шаг 1Читаем документы

import glob, os

def load_docs(folder: str = "docs") -> list[dict]:
    docs = []
    for path in glob.glob(f"{folder}/*.md"):
        text = open(path, encoding="utf-8").read()
        docs.append({"source": os.path.basename(path), "text": text})
    return docs

docs = load_docs()
print("Документов:", len(docs))

Шаг 2Простая нарезка по длине 

def chunk_text(text: str, size: int = 500) -> list[str]:
    return [text[i:i + size] for i in range(0, len(text), size)]

print(len(chunk_text(docs[0]["text"])))

Шаг 3Нарезка с перекрытием

def chunk_overlap(text: str, size: int = 500, overlap: int = 80) -> list[str]:
    chunks, start = [], 0
    while start < len(text):
        chunks.append(text[start:start + size])
        start += size - overlap        # перекрытие сохраняет контекст на границах
    return chunks

Шаг 4Чанки с метаданными

def build_chunks(docs: list[dict]) -> list[dict]:
    out = []
    for d in docs:
        for i, c in enumerate(chunk_overlap(d["text"])):
            out.append({"id": f'{d["source"]}-{i}',
                        "source": d["source"], "text": c})
    return out

chunks = build_chunks(docs)
print("Всего чанков:", len(chunks))

Шаг 5Проверяем качество нарезки 

for c in chunks[:3]:
    print(c["id"], "|", c["text"][:60].replace("\n", " "), "...")
Вывод: размер чанка и перекрытие — главные ручки RAG. Слишком крупно — дорого и неточно; слишком мелко — теряется смысл.
Задание 5.2

Embeddings и vector DB

Что делаем: превращаем чанки в векторы и кладём в базу. Зачем: эмбеддинги позволяют искать по смыслу, а не по точному совпадению слов.

Шаг 1Функция эмбеддинга

from openai import OpenAI
from dotenv import load_dotenv
load_dotenv()
client = OpenAI()

def embed(text: str) -> list[float]:
    r = client.embeddings.create(model="text-embedding-3-small", input=text)
    return r.data[0].embedding

Шаг 2Смысловая близость на примере 

import numpy as np

def cosine(a, b) -> float:
    a, b = np.array(a), np.array(b)
    return float(a @ b / (np.linalg.norm(a) * np.linalg.norm(b)))

print(cosine(embed("отпуск"), embed("отгул")))      # близко
print(cosine(embed("отпуск"), embed("процессор")))  # далеко

Шаг 3Создаём коллекцию

import chromadb
db = chromadb.Client()
col = db.get_or_create_collection("knowledgebot")

Шаг 4Загружаем чанки (ingestion) 

def ingest(chunks: list[dict]):
    col.add(
        ids=[c["id"] for c in chunks],
        embeddings=[embed(c["text"]) for c in chunks],
        documents=[c["text"] for c in chunks],
        metadatas=[{"source": c["source"]} for c in chunks],
    )

ingest(chunks)                      # chunks из задания 5.1
print("В базе объектов:", col.count())

Шаг 5Проверяем сохранность

peek = col.get(limit=2)
print(peek["ids"], peek["metadatas"])
Вывод: ingestion = нарезка + эмбеддинги + сохранение с метаданными (источником). Источник понадобится для ссылок в ответе.
Задание 5.3

Retrieval

Что делаем: по вопросу находим самые близкие чанки. Зачем: качество ответа RAG ограничено качеством поиска — это оценивают отдельно от генерации.

Шаг 1Базовый поиск

def retrieve(question: str, k: int = 3) -> list[dict]:
    res = col.query(query_embeddings=[embed(question)], n_results=k)
    hits = []
    for text, meta in zip(res["documents"][0], res["metadatas"][0]):
        hits.append({"text": text, "source": meta["source"]})
    return hits

for h in retrieve("Сколько дней отпуска?"):
    print(h["source"], "|", h["text"][:50])

Шаг 2Смотрим дистанции

res = col.query(query_embeddings=[embed("Сколько дней отпуска?")],
                n_results=3, include=["distances", "metadatas"])
print(list(zip(res["metadatas"][0], res["distances"][0])))

Шаг 3Порог релевантности

def retrieve_filtered(question: str, k: int = 3, max_dist: float = 0.6):
    res = col.query(query_embeddings=[embed(question)],
                    n_results=k, include=["documents", "metadatas", "distances"])
    hits = []
    for text, meta, dist in zip(res["documents"][0],
                                res["metadatas"][0], res["distances"][0]):
        if dist <= max_dist:          # отсекаем нерелевантное
            hits.append({"text": text, "source": meta["source"]})
    return hits

Шаг 4Проверяем нерелевантный запрос 

print(retrieve_filtered("Какая погода на Марсе?"))  # ожидаем пустой список

Шаг 5Мини-оценка retrieval

eval_q = [("Сколько дней отпуска?", "vacation.md"),
          ("Как сбросить пароль?", "account.md")]
hits_at_1 = 0
for q, expected in eval_q:
    top = retrieve_filtered(q, k=1)
    if top and top[0]["source"] == expected:
        hits_at_1 += 1
print(f"Hit@1: {hits_at_1}/{len(eval_q)}")
Вывод: retrieval измеряется отдельно (Hit@k). Если поиск не нашёл нужный чанк, никакая модель не спасёт ответ.
Задание 5.4

Grounding и источники

Что делаем: генерируем ответ строго по найденным чанкам и прикладываем источники. Зачем: ответ без источника нельзя проверить; grounding снижает галлюцинации.

Шаг 1Собираем контекст

def build_context(hits: list[dict]) -> str:
    return "\n---\n".join(f'[{h["source"]}] {h["text"]}' for h in hits)

Шаг 2Prompt с требованием grounding 

RAG_PROMPT = """Ответь на вопрос, используя ТОЛЬКО контекст ниже.
Если ответа в контексте нет — ответь: "Информация не найдена в базе знаний".
Контекст:
{context}

Вопрос: {question}"""

Шаг 3Полный RAG-ответ

from llm_client import LLMClient
bot_llm = LLMClient()

def answer(question: str) -> dict:
    hits = retrieve_filtered(question, k=3)
    if not hits:
        return {"answer": "Информация не найдена в базе знаний.", "sources": []}
    prompt = RAG_PROMPT.format(context=build_context(hits), question=question)
    text = bot_llm.ask(prompt)
    sources = sorted({h["source"] for h in hits})
    return {"answer": text, "sources": sources}

print(answer("Сколько дней отпуска?"))
print(answer("Какая погода на Марсе?"))

Шаг 4Проверяем честный отказ 

res = answer("Сколько стоит подписка на Netflix?")
assert "не найдена" in res["answer"].lower()
assert res["sources"] == []
print("Отказ при отсутствии данных работает.")

Шаг 5Показ источников пользователю 

def format_reply(res: dict) -> str:
    out = res["answer"]
    if res["sources"]:
        out += "\n\nИсточники:\n" + "\n".join(f"- {s}" for s in res["sources"])
    return out

print(format_reply(answer("Как сбросить пароль?")))
Вывод: правило «отвечай только по контексту + покажи источник» — ядро доверенного ассистента.
Задание 5.5

Advanced RAG

Что делаем: добавляем переформулировку запроса, гибридный отбор и переоценку. Зачем: базовый RAG часто промахивается на синонимах и общих формулировках.

Шаг 1Расширяем запрос (query expansion) 

def expand_query(q: str) -> str:
    syn = bot_llm.ask(f"Дай 3 синонима/переформулировки запроса одной строкой: {q}")
    return q + " " + syn

Шаг 2Берём больше кандидатов 

def retrieve_many(question: str, k: int = 8) -> list[dict]:
    res = col.query(query_embeddings=[embed(expand_query(question))], n_results=k)
    return [{"text": t, "source": m["source"]}
            for t, m in zip(res["documents"][0], res["metadatas"][0])]

Шаг 3Переоценка (rerank) моделью 

def rerank(question: str, hits: list[dict], top: int = 3) -> list[dict]:
    scored = []
    for h in hits:
        s = bot_llm.ask(
            f"Оцени от 0 до 10, насколько фрагмент отвечает на вопрос. "
            f"Только число.\nВопрос: {question}\nФрагмент: {h['text']}")
        try:
            scored.append((float(s.strip()), h))
        except ValueError:
            scored.append((0.0, h))
    scored.sort(key=lambda x: x[0], reverse=True)
    return [h for _, h in scored[:top]]

Шаг 4Собираем продвинутый ответ 

def answer_advanced(question: str) -> dict:
    candidates = retrieve_many(question)
    best = rerank(question, candidates)
    if not best:
        return {"answer": "Информация не найдена в базе знаний.", "sources": []}
    prompt = RAG_PROMPT.format(context=build_context(best), question=question)
    return {"answer": bot_llm.ask(prompt),
            "sources": sorted({h["source"] for h in best})}

print(answer_advanced("Сколько отгулов положено сотруднику?"))

Шаг 5Сравниваем базовый и продвинутый RAG 

q = "Что делать, если деньги списали дважды?"
print("base:    ", answer(q)["sources"])
print("advanced:", answer_advanced(q)["sources"])
